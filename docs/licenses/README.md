# Licences and provenance of what the installer distributes

- `asset-inventory.json` — every file under `assets/` with the decision (ship / withhold), the licence evidence and the reason.
  Regenerate: `node packages/forge-desktop/scripts/asset-inventory.mjs --write`. The rule is an **allowlist by positive evidence**
  (ADR-0052 §3). Result today: 0 of 296 files ship; **no EmptyEpsilon-derived image or model is in the installer**.
- `THIRD-PARTY-NOTICES.txt` — the npm libraries bundled into the editor and the desktop shell with their licence texts (generated by
  `packages/forge-desktop/scripts/notices.mjs` at build time; this is a copy of the one that ships beside the program).
  Electron's and Chromium's own notices ship as `LICENSE.electron.txt` / `LICENSES.chromium.html`.
- Not decided here: the licence of EE FORGE's own code (the owner has not chosen one; nothing asserts one).
- Open question for the owner: whether the upstream EmptyEpsilon `resources/` images (planets, radar, nebula) may be redistributed
  — the repository's earlier README says "GPLv2", which could not be confirmed from upstream's README. Until it is, they are
  imported from the user's own install.
